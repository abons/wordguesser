The Android app

Word Guesser is also a tiny (~102 KB) native Android app, and it is moving to Google Play — until that listing is live there is no way to install it for the first time. If you already have it, keep it: it works offline and nothing about it expires. This page and the app share the same daily word and the same leaderboard. The releases page lists what changed per version.
